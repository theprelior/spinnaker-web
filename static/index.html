Getting Started

1

Pick a template from the sidebar or write your own Python code.

2

Click ▶ Run (or Ctrl+Enter) to submit to real SpiNNaker2 hardware.

3

Watch the terminal for live output. Jobs run one at a time — yours will queue if hardware is busy.

4

When done, use ⊞ View to browse output files and plots, or ↓ Download for a .tar.gz archive.

Templates

8 built-in SpiNNaker2 examples: LIF neurons, current-based synapses, Poisson inputs, Izhikevich model, adaptive LIF, and a 5-group synfire chain. Each template runs out of the box.

Hardware Queue

SpiNNaker2 executes one job at a time. Click the hardware status dot in the header to see the live queue, your position, and the estimated wait time.

Quota & Limits

Each user may submit up to — jobs per hour. Your usage is shown as a badge in the header. Scripts may run for up to 5 minutes before timing out.

Reproducibility

Open ⊞ View → Job Info after a run to see software versions, hardware details, and timestamps. Use Export Metadata to download a JSON snapshot for your methods section.

Compare Runs

In the Recent Jobs sidebar, click ⊕ on a completed job, then ⊕ on another to view their outputs side by side.

Share Code

Click Share in the toolbar to generate a 30-day link anyone can use to load your code directly into the editor.

Keyboard Shortcuts

Ctrl+Enter Run  ·  Ctrl+S Save  ·  Ctrl+B Toggle sidebar  ·  Esc Close modals
